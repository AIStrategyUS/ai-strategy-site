What This Is

This is a private demo built for Fork & Fire ownership to experience what an optimized AI voice ordering agent looks and feels like in practice. The agent below is configured for the Oro Valley Smokehouse + Taproom location and has full knowledge of your menu, hours, specials, and both locations.

This demo is designed to show the conversational capability of the agent — how naturally it handles ordering, location transfers, and customer requests. It does not include phone intake or POS integration. Those would be part of a full implementation.

How It Works

01

Start the Conversation

Click the widget below and begin speaking or typing. The agent will greet you as if you called the Oro Valley location.

02

Place an Order

Ask about the menu, place an order for pickup or dine-in, or inquire about reservations. The agent knows your full menu.

03

Test the Logic

Try transferring to the Catalina location or asking for a real person. The agent will hand off cleanly to the appropriate agent.

Things to Try

🍖

Place a Standard Order

Order a sandwich, plate, or any menu item and see how the agent handles the full ordering flow — including sides, add-ons, and payment.

"I'd like the pulled pork sandwich for pickup"
📍

Transfer to Catalina Location

Tell the agent you meant to call the Catalina location and watch it hand off cleanly to the Catalina Grill agent.

"Actually, I meant to call the Catalina location"
👤

Request a Real Person

At any point, ask to speak with a team member and the agent will confirm and transfer you to the human fallback agent.

"Can I speak to a real person?"
🗓️

Make a Reservation

Ask about making a reservation and see how the agent collects party size, date, and time — something the current Toast agent doesn't handle.

"I'd like to make a reservation for Saturday"

Demo Scope & Limitations

No Phone IntakeThis demo runs via web widget. A full implementation would handle inbound phone calls directly.

No POS IntegrationOrders are not sent to your kitchen or Toast system. This demonstrates the conversation layer only.

No Payment ProcessingThe agent will simulate the payment link flow but no actual transactions are processed.

Conversation OnlyThis is purpose-built to show how the agent converses, handles your menu, and manages handoffs.
